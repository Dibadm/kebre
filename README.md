# Kebre Ilike PLC

Kebre Ilike PLC is an Ethiopian enterprise specializing in the export of specialty coffee and the import of pharmaceutical and medical supplies.

## Business Focus

- **Coffee Export**: Specialty Arabica coffee from the Yayo Biosphere Reserve and Jimma region, Southwestern Ethiopia.
- **Pharma Import**: Import and distribution of pharmaceutical products and medical consumables across Ethiopia.

## Tech Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Development

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
```
